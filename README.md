# 轻松农场作物成熟追踪（浏览器扩展）

记录“黑与白福利站”轻松农场全部地块的作物成熟时间，在扩展图标上显示最近成熟作物的倒计时，点击弹出紧凑面板查看地块成熟时间与提醒。

## 特性

- **被动记录**：通过 hook 页面自身的 `fetch`/`XMLHttpRequest` 捕获 `/api/farm/crops` 响应，不主动发起任何请求、不执行任何页面操作。
- **页面数据优先**：播种/收获可能在其他客户端进行；以页面数据为准，本地记录冲突时覆盖。
- **去重压缩**：播种是批量进行的，相同成熟时间（按作物/等级/成熟时刻）聚合数量。
- **图标徽章**：显示最近一个成熟作物的倒计时，成熟后变绿并显示“熟”。
- **紧凑面板**：聚合后的地块列表直接平铺展示，逐条显示等级、数量、剩余时间（彩色）与成熟时刻（绝对时间）。
- **提醒**：支持 0/多 个提醒，可设「提前/滞后」相对最近成熟时间的秒数，逐条启用/禁用、预览预计提醒时间、上移/下移/删除（悬停显示操作），触发浏览器通知，点击通知跳转农场标签页（或新开）。

## 安装（开发）

Chrome（Manifest V3）：

1. 打开 `chrome://extensions`
2. 右上角开启「开发者模式」
3. 「加载已解压的扩展程序」→ 选择本目录 `src/`

> 后台为 MV3 service worker，会被休眠；徽章/提醒由 `chrome.alarms`（最小 1 分钟）驱动刷新，因此图标徽章倒计时以分钟粒度更新。
